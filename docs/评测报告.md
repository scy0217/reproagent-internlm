# ReproAgent 评测报告

## 1. 当前已验证结果

### 1.1 Python 确定性数值核验

测试集：`benchmarks/numeric_cases.json`，共 8 个案例，覆盖相对下降、相对上升、百分比变化、差值、绝对差值、比值、错误主张和零基准异常。

复现命令：

```powershell
python scripts/run_numeric_benchmark.py
```

当前结果：8/8 状态判断正确，工具级状态准确率 100%。该指标只证明 Python 数值核验工具在已支持操作上的确定性行为，不代表完整智能体的实验要素提取、问题发现或证据定位准确率。

### 1.2 自动化回归测试

当前测试覆盖：

- 数值主张的一致、不一致和错误输入。
- LangGraph 数值条件分支、反思触发和循环上限。
- “代码未公开”只影响资源开放性的评分隔离规则。
- ZIP 复现材料只读目录、不执行代码。
- 科学记数法规范化和损坏符号问题隔离。

复现命令：

```powershell
python -m unittest discover -s tests -v
```

## 2. 完整智能体评测计划

完整系统必须使用人工标注公开论文评估，不能用工具级单元测试代替。建议构建至少 20 篇论文的测试集，报告以下指标：

| 能力 | 指标 | 计算方式 |
|---|---|---|
| 实验要素提取 | 字段准确率 | 正确字段数 / 已标注字段数 |
| 证据定位 | 页码准确率 | 正确页码证据数 / 已标注证据数 |
| 问题发现 | Precision / Recall / F1 | 与双人复核金标准比对 |
| 误报过滤 | 误报下降率 | 初审误报数与复核后误报数比较 |
| 稳定性 | 结构化字段一致率 | 同一输入独立运行 3 次比较 |
| 效率 | 时间降低率 | 人工完成时间与智能体时间比较 |
| 端到端可靠性 | 成功率 | 完整生成报告次数 / 总运行次数 |

## 3. 消融实验

分别关闭 Python 数值工具、证据复核和反思回环，对同一测试集重新运行，比较数值错误率、误报率与低证据问题召回率。最终技术文档应报告真实测量值、样本数和失败案例，不得把目标值当作已达到成绩。
